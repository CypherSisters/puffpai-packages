# PuffPAI packages

The Cypher Sisters' own packages for the [PuffPAI Store](https://github.com/CypherSisters/puffpai-store). One folder per package, each with its own `puffpai.json` and README. The store's index points at a folder here and pins one commit.

Every app and tool ships off. Turn one on from Apps, PuffPAI store. A tool package has no page of its own: the brain uses it in chat.

**Check a package:** `puffpai check <folder>` from a PuffPAI install. Level 3 is the store's bar. Each package with a server also has its own `tests/test_server.py` (run with pytest from a PuffPAI install).

**Talking to something on your home network.** `home-assistant`, `jellyfin`, `adguard`, `node-red-flows` and `web-search` (when you save a SearXNG address) reach a service you run yourself. Each saves the address you give it (only an address on this computer or your home network) and keeps the key or login from the environment the Core sets, never on disk. A service on this same computer needs no further step. For one on another computer, the package asks the Core for a Yes card for that exact address and port (its manifest says `needs.addresses: lan`), nothing reaches it until you say Yes, and you can take the allowance back on the Bridge page or type an address there yourself. `news-headlines` works the same way for each feed's site on the internet (`needs.addresses: internet`). These six need a PuffPAI with that card (D110); an older PuffPAI does not take their manifests.

**Where these came from.** The five apps, the looks and the avatars were copied from BuildBotv2 `packages/` and are kept the same in both places. The tools, the two new apps and the skill were rewritten from the HomeBotFounders build (commit `b77fc40`) to the v2 package contract; each `server.py` names its source file on its first line. `look-clean` stays in this repo for history only: Clean became a built-in look (D90) and has no store row.
