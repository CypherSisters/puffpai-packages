# Clean

A look for the PuffPAI Desktop (kind `look`, D76). Clean: square corners, flat colours, thin 1px rules and dense spacing, with JetBrains Mono headings. Near-black at night, off-white by day, one blue accent. No glow, no clouds.

It is values only: CSS variables the Desktop already reads, in `puffpai.json`. No CSS file, no script, no font file, nothing loaded from the internet. Add it from Apps, PuffPAI store, then pick it on Looks.

`preview.svg` shows it at night (left) and by day (right).

## PuffPAI

**What it does.** Changes how the PuffPAI Desktop looks: colours, corners, fonts and spacing. It is values only, CSS variables the Desktop already reads. It runs nothing.

**What it needs.** Nothing: no process, no internet, no keys, no personal data.

**Setup.** Add it from Apps, PuffPAI store, then pick it on Looks. Remove it any time; the Desktop goes back to Puff.
