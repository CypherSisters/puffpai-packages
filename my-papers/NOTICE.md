All code here was written for this package. No code was copied from any other project.

- **The fields of a paper** follow what open document managers have settled on: a title, who sent it (a correspondent), a document type, tags, the date on the document and the date it was added, and a binder number for where the paper copy lives. The ideas, and only the ideas, come from Paperless-ngx (GPL-3.0; no code copied) and Papermerge (Apache-2.0). Real due dates, expiry dates and renewals are this package's own addition.
- **Search** uses SQLite FTS5 through Python's own `sqlite3` module. SQLite is in the public domain.
- **The tax keeping hint** ("Most tax records: keep 3 years. Some need longer.") comes from the United States IRS public guidance "How long should I keep records". It is a hint only, not advice for any one person.
